# Clay Hub – Android APK
1. Create a new GitHub repo and upload everything in this folder (keep the .github folder).
2. Open the repo's Actions tab -> "Build APK" (it runs on every push, ~4-6 min).
3. Open the finished run -> Artifacts -> clay-hub-apk -> download, unzip, install app-debug.apk on your phone.
Edit www/index.html to change the app, push again, get a new APK.
